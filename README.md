# 🚀 FreeAPI Explorer (ChaiTube)

A premium, all-in-one exploration platform powered by **FreeAPI**. This application features a suite of high-fidelity modules ranging from video streaming and e-commerce to gourmet recipes and community directories—all wrapped in a stunning "Premium Glassmorphism" aesthetic.

![ChaiTube Header](./public/app.jpeg)

## ✨ Features

### 📺 Video Streaming
*   High-performance video grid with category sorting.
*   Full-screen immersive video player with related content suggestions.
*   Persistent search state and smooth playback transitions.

### 🛍️ Smart Marketplace
*   Browse diverse product categories with advanced filtering.
*   Detailed product modals featuring price points, ratings, and descriptions.
*   Context-aware searching across thousands of items.

### 🍽️ Gourmet Kitchen
*   Discover recipes from around the globe with origin and category badges.
*   Step-by-step cooking instructions and ingredient checklists.
*   Direct integration with YouTube cooking tutorials.

### 🐱 Cat Breed Spotlight
*   Interactive breed explorer with intelligence, energy, and affection ratings.
*   Detailed breed histories and Wikipedia integration.
*   Favorite and share your favorite feline friends.

### 👤 Global User Directory
*   High-fidelity member profiles with verified identity badges.
*   Location-intelligent contact cards and registration history.
*   Advanced search for finding community members by name or location.

### 💡 Wisdom & Humor Hubs
*   **Quote Gallery**: Timeless wisdom from great thinkers with one-click copy/share.
*   **Laugh Factory**: Endless humor with category-tagged joke cards.

## 🛠️ Tech Stack

*   **Frontend**: [React.js](https://reactjs.org/) (Vite)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Routing**: [React Router DOM](https://reactrouter.com/)
*   **Animations**: Custom Tailwind `animate-in` & `backdrop-blur`

## 🔍 Advanced Search Features

### 🎤 Voice Search
Experience hands-free exploration. Click the microphone icon to search any tab using the **Web Speech API**. Featuring real-time visual feedback and pulsing violet brand highlights.

### 🔄 Context-Aware Logic
The search bar dynamically adapts to your current location. Whether you're searching for "Jokes" or "Recipes", the system automatically adjusts its placeholders and API queries to match your intent.

### 🔗 Bookmarkable State
Every search and navigation action is synced with the URL query parameters (`?q=...`). Share a link to a specific search result or bookmark your favorite filtered view effortlessly.

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-repo/freeapi-explorer.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
